# Task Manager Application

A full-stack Task Manager web application built with **Node.js**, **Express**, and **MongoDB**, featuring a clean frontend interface for seamless task management.

## 🚀 Features

* **Add & Delete Tasks**: Create new tasks and remove them upon completion.
* **Persistent Storage**: Integrated with MongoDB and Mongoose so your data remains safe even after server restarts.
* **RESTful API**: Clean backend routes built using Express.js.
* **Responsive UI**: Simple and intuitive user interface.

---

## 🛠️ Tech Stack

* **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
* **Backend**: Node.js, Express.js
* **Database**: MongoDB, Mongoose
